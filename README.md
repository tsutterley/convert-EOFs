# convert-EOFs

[![License](https://img.shields.io/github/license/tsutterley/convert-EOFs)](https://github.com/tsutterley/convert-EOFs/blob/main/LICENSE)

Python tools for ``ruining'' EOFs as described in Medley, Sutterley and Siegfried (2025).

For more information on the background processing: see the documentation at [gravity-toolkit.readthedocs.io](https://gravity-toolkit.readthedocs.io/)

## Installation with Pixi

You can use [Pixi](https://pixi.sh/) for a streamlined workspace environment:

1. Install Pixi following the [installation instructions](https://pixi.sh/latest/#installation)
2. Clone the project repository:

```bash
git clone https://github.com/tsutterley/convert-EOFs.git
```

3. Move into the `convert-EOFs` directory

```bash
cd convert-EOFs
```

4. Install dependencies and start a shell to run programs:

```bash
pixi shell
```

This will automatically create the environment, install all dependencies, and allow running the package scripts.

## Dependencies

- [gravity-toolkit: Python tools for working with GRACE/GRACE-FO data ](https://github.com/tsutterley/gravity-toolkit/)
- [model-harmonics: Python tools for working with model synthetic spherical harmonic coefficients](https://github.com/tsutterley/model-harmonics/)
